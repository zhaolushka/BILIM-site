Контент-план BILIM: сайт

Как открыть: дважды нажмите на index.html, он откроется в браузере.
Нужен интернет только для шрифтов, всё остальное работает без него.

Важно:
- В этой копии изменения (новые посты, ссылки, статусы) сохраняются
  только в том браузере и на том компьютере, где вы их сделали.
  Другие люди их не увидят.
- Общая версия, где правки видит вся команда, работает по ссылке в Claude.

Чтобы выложить сайт в интернет, загрузите папку на любой хостинг
статических сайтов (например, Netlify Drop, GitHub Pages, Tilda Zero-блок).
